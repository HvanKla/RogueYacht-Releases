# Rogue Yacht — Beta Releases

Publieke downloadrepo voor **Rogue Yacht**: een Yahtzee-roguelike in Balatro-stijl.
Dobbelstenen, jokers, relics, custom dice, en een scoringsysteem dat chips × multiplier
laat ontploffen met alle juice die erbij hoort.

- Sourcecode staat in een privérepo.
- Hier komen alleen de **Windows- en Linux-beta-builds** (pre-releases).

## Download

Ga naar het tabblad **Releases** en pak de zip voor jouw OS:

| Bestand | Platform |
|---|---|
| `RogueYacht-beta-<versie>-win64.zip` | Windows 10/11 (64-bit) |
| `RogueYacht-beta-<versie>-linux-x86_64.zip` | Linux (x86_64) |

## Systeemvereisten (beta)

- Windows: DirectX 11 of Vulkan, 4 GB RAM.
- Linux: Vulkan of OpenGL 3.3, 4 GB RAM.

## Changelog & feedback

Elke release bevat changelog-notities. Meld bugs via GitHub **Issues** in deze repo.
